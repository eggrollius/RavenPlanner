Captured from the running application at `http://localhost:5173` using
`npm run dev`, Node.js 22, and headless Chromium with a 1440 × 1100 viewport.
These are browser screenshots of the React UI, Express API, and seeded PGlite
database running together in the development environment.

- `01-local-startup.png`: initial planner with all three seeded term choices.
- `02-seeded-course-plan.png`: COMP 1405, MATH 1007, and PSYC 1001, including
  lecture/tutorial selection and 22 conflict-free schedule options.

  COMP 1405 lecture A disabled, and an Online Unscheduled CGSC 1001 section;
  viewing the second of 16 remaining schedule options.
